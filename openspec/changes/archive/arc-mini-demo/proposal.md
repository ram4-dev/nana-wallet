# Arc mini demo

Preparar una wallet Circle developer-controlled EOA en Arc Testnet para una
demostracion local de Nani. Preservar el producto WDK y no hacer la migracion
completa en este cambio. El usuario fondea la wallet y confirma cada pago.

Primera entrega: setup privado y repetible, direccion publica para fondeo.
Segunda entrega aceptada: demo escrita aislada, restringida a Arc Testnet y
USDC, con preview y confirmacion explicita. No integra todavia el agente
existente ni reemplaza WalletProvider. El usuario autoriza publicar en main.

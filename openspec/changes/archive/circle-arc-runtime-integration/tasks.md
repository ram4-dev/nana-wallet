Rationale: the change is a wiring-plus-hardening bridge over a rescued provider. It touches the provider (`src/wallet/circle-arc-provider.ts`: hardened `waitForFinality` + chainId pre-check + receipt-hash echo), two policy gates (`src/agent/definition.ts`, `src/agent/wallet-agent.ts`), the idempotency seam (three construction sites: `buildGuardedTools`, `toTransferRequest`, `sendToken`), the confirm-branch provider routing and receipt-waiter selection, the explorer URL normalization, the additive `/health` provider field, the D8 boot guard, `.env.example`, docs, and a new fake-Circle integration test — plus extensions to the provider, policy, health, and seam unit suites. Because it crosses the provider seam and the text/voice confirmation flow, the slices are independently revertible (provider + seam reverted without touching the policy gate or health contract), which keeps review diffs focused.

## Native review candidate and delivery discipline

The native bounded review candidate is **one work-unit commit** — never a checkbox, never a task line,
and never the accumulated `feat/solana-operational` branch. All source-mutating normalizers must run
**before** the candidate is frozen; after the freeze only check-only commands may run.

```text
npm run lint          # the only source-mutating normalizer; must be convergent (a second run is a no-op)
npm run typecheck
npm test              # with docker compose up -d db
npm run eval
(cd apps/nana-wallet && npm run lint && npm run typecheck && npm test)
```

`openspec/config.yaml` declares `formatter: false`, so there is no format step. Any byte, path, or mode
change after the freeze invalidates the receipt and requires re-normalization plus a new review of the
new bytes. The receipt records the frozen commit SHA, the tracked-file state, the exact commands and
results, and the baseline comparison by test name.
